Read the utility meter shown in the image above.

READING — the main consumption counter:
- Read ALL digit positions left to right, including leading zeros.
- Decimal separator rules (exactly one decimal separator is possible):
  • If you see BOTH a period (.) AND a comma (,): the period is a thousands separator — ignore it. The comma is the decimal separator — write it as a period (.) in your answer.
  • If you see only a period (.): it is the decimal separator — keep it as a period (.) in your answer.
  • If you see only a comma (,): it is the decimal separator — write it as a period (.) in your answer.
  • If you see no separator at all: return only the integer digits (e.g. '1374', NOT '1374.' or '1374.0').
- READING SOURCE: the consumption counter is ONLY the row of mechanical ROLLING DRUMS (odometer-style digit wheels behind small windows) or the LCD value. Numbers PRINTED flat on the dial face — large serial numbers, approval codes like M24/M26, DE-xx-MI001-... — are NEVER the reading. If you see both a printed number and a drum row, the drums are the reading.
- RED DRUMS (only if the display really has mechanical drums with red ones; an LCD has none): digits on RED drums are the FRACTIONAL part. The decimal separator sits immediately before the FIRST red digit. Black drums are the integer part. Example: black drums 00000 followed by red drums 582 = '00000.582'.
- SEPARATOR LOCATION HINT: fractional digits are usually visually distinct (boxed, underlined, or right of the printed decimal point). Electricity meters (kWh) typically show exactly 1 fractional digit, water meters (m³) exactly 3, oil level displays (Ltr.) none. Use this to locate the true separator position. If the digits show no separator at all and the meter type is clear (kWh or m³), place it so that exactly that many digits follow it.
- A separator that is visible between digits (even a small dot or comma on an LCD) MUST appear in your answer at that exact position. Never invent trailing zeros or fractional digits that are not shown (no '.000' or '.0' appended; if the display shows 6 digits, answer with 6 digits plus at most the one separator).
- NEVER DROP DIGITS: if you are unsure where the separator belongs, output every digit and every separator exactly as you see them — a doubled separator is acceptable, a missing digit is not.
- Do NOT skip any drums or windows, even if dim or partially rotated.
- Ignore handwritten numbers, stickers, adhesive labels, or annotations.
- No spaces, no units (kWh/m³/…).

SERIAL — the device identifier on the meter label:
- Candidates: the text line under or next to a barcode, a label with S/N, MSN, Nr. or Zähler-Nr., or a number printed flat on the dial face.
- If several candidates exist, choose the LONGEST one that mixes letters and digits (typically 10-14 characters, often the line printed with the barcode). A short purely numeric 'Nr.' is only the answer if nothing longer exists. Handwritten numbers are never the serial.
- Serials are often printed in spaced groups (e.g. 'A 1BC23 4567 8901'): join all groups into one string and keep the very first character even if it is separated by a gap.
- Approval/calibration codes (M24, M26, DE-xx-MI001-PTBxxx) are NOT the serial.
- Copy only the characters belonging to THAT one label — do not merge multiple labels.
- Include ALL leading zeros exactly as printed.
- Only alphanumeric characters (A–Z, 0–9) — strip ALL spaces and punctuation (the answer must contain none).
- If no serial label is visible, use null.

If a field is unreadable, use the JSON value null (not the string "null").
Return raw JSON only, no code fences. A missing field is the JSON literal null without quotes.
