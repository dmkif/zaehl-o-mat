## Rig/test follow-ups before re-running this group

1. Make the shared httpx clients resilient to server-closed keep-alive sockets (retries / no keepalive / retry-once in `send` and `make_world`). Otherwise every 500 poisons the next request and A05 produces false findings and setup failures.
2. Fix the `pwned in head` false positive in the A05 header test.
3. A01_006 dynamic test is blocked by the 500 on dict `integration_config`; once fixed (or if the test sends a JSON string) the SSRF check runs.
4. Several A04/A05 tests need the signing key and are therefore low severity; keep them as hardening regressions.
